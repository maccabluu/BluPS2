# BluPS2 Public Alpha 1.0

BluPS2 is an experimental PS2 emulator project for Android, with a custom blue handheld-focused interface and the open-source Play! PS2 emulation core.

## Public Alpha status

BluPS2 Public Alpha 1.0 is an early testing release. Game compatibility, graphics, audio, controls and performance vary between titles and devices.

## Features

- PS2 emulation powered by the Play! core
- ARM64 Android build
- BluPS2 blue game-library interface
- Add Games and Refresh shortcuts
- Recent and Favorites sections
- Profiles
- Controller settings shortcut
- Controller vibration test
- Performance Hub
- 30 FPS and 60 FPS target presets
- Live battery percentage
- Device temperature display where Android exposes a readable sensor
- Android thermal-status display and Smart Heat Guard information
- Landscape handheld interface

## Installation

1. Download the BluPS2 Public Alpha 1.0 APK from the GitHub Release.
2. Install the APK on an ARM64 Android device.
3. Open BluPS2.
4. Add your own legally dumped PS2 game files through the library.
5. Test your games and report problems through GitHub Issues.

## Important

BluPS2 does not include PS2 games, copyrighted game files or Sony system software. Use game files you are legally entitled to use.

A 60 FPS target does not guarantee a game will run at 60 FPS. Actual performance depends on the game, device and emulation-core compatibility.

## Known Alpha limitations

- Compatibility differs between PS2 games.
- Some games may fail to boot or have graphics, audio or controller problems.
- Performance telemetry depends on information exposed by the Android device.
- The interface and settings are still under development.
